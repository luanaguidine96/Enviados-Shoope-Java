# Enviados da Shopee

Projeto desenvolvido em Java para simular o gerenciamento de produtos enviados, utilizando recursos de programação funcional e concorrência.

## Tecnologias

* Java
* Collections
* Stream API
* Lambda Expressions
* Functional Interfaces
* LocalDate
* Multithreading

## Conceitos praticados

O projeto trabalha com armazenamento de pedidos em listas, processamento utilizando Stream API e execução de tarefas através de Threads e Functional Interfaces.

## Objetivo

Praticar conceitos modernos de Java por meio de uma aplicação simples e baseada em uma situação do cotidiano.
